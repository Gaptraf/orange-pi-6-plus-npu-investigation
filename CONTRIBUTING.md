# Contributing evidence and corrections

Corrections, independent replications, vendor explanations, and faster implementations are welcome.

Please include the board variant, RAM size, image/kernel/firmware versions, driver and SDK versions, exact model revision and quantization, complete commands, and raw results. For performance claims, state the warmup, sample count, statistic, timing boundary, thread affinity, clocks, and whether profiling is enabled.

Check numerical correctness before quoting speed. Compare the same workload and identify any differences in precision or output quality. Label a projection benchmark, hybrid block, complete model, prefill test, and decode test accurately.

Do not include credentials, private network details, model weights, or vendor binaries that you cannot redistribute. A specific public source or diagnostic record is more useful than an unsupported accusation.

We will correct mistakes in the narrative when evidence warrants it. Favorable NPU results belong in the record too.
